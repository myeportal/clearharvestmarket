Role model

Superadmin

  • Manage all env secrets and API keys
  • Approve automation channels
  • Change offer stack and payment routing
  • Create and retire agents
  • Override owner permissions

Admin

  • Run approved campaigns
  • Manage content queue
  • Review leads and funnel status
  • Adjust copy and local offers
  • No access to top-level secrets

Agent orchestration

SEO Agent

Local keyword research, metadata, landing briefs, FAQ expansions, schema suggestions.

Video Agent

Short-form promo prompts, shot lists, ad hooks, and product-video queueing.

Autopost Agent

Turns approved content into channel-specific post drafts with CTA and tracking links.

Lead Gen Agent

Creates lead magnets, opt-in paths, and local audience segmentation ideas.

Funnel Agent

Connects lead source → landing page → offer → checkout → upsell → follow-up.

Payments Agent

Maintains product/payment protocol maps and post-purchase workflow logic.

Automation guardrails

Recommended rule

Publishing and paid/off-platform actions should stay approval-based unless explicitly enabled by superadmin.

Allowed autopilot zones

  • Draft generation
  • SEO brief creation
  • Video prompt generation
  • Lead tagging
  • Internal funnel recommendations

Unified funnel model

  • Social / SEO / video / local guide content → lead capture
  • Lead capture → list tagging by intent
  • Intent tag → recipe / Hotplate / catering / bundle / future direct checkout offer
  • Offer purchase → thank-you + next best offer
  • Post-purchase → loyalty, referrals, repeat orders, and seasonal campaigns
